# 🎓 Student Grade Calculator (Java OOP Project)

A professional console-based Java application designed to automate student grading while demonstrating core **Object-Oriented Programming (OOP)** concepts.

---

## 🎯 Project Objective

This project was developed as part of a university assignment to transition from basic programming to **structured OOP design**. It focuses on implementing real-world concepts such as inheritance, polymorphism, and clean architecture in Java.

---

## 🚀 Features

- 👤 Dynamic student input (name, mark, type)
- 🎯 Automatic grade calculation
- 🔄 Support for multiple student types:
  - Regular Students
  - Extension Students (custom grading logic)
- 📊 Real-time report generation
- 🧠 Demonstrates core Java OOP principles

---

## 🛠️ Tech Stack

- **Language:** Java  
- **Library:** java.util.Scanner  
- **Concepts Used:**  
  - Inheritance  
  - Polymorphism  
  - Method Overriding  
  - Encapsulation  
  - Access Modifiers  
  - Static Methods
